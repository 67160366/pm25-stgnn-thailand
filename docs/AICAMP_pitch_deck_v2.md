## โครงสไลด์ v2 (12 สไลด์)

### 1. ปก / Hook
- ชื่อ + ภาพภาคเหนือจมหมอกควัน + จุดไฟ FIRMS
- พูด: "ทุกฤดูแล้ง ภาคเหนือจมฝุ่นที่ไม่ได้มาจากเราคนเดียว—มันข้ามพรมแดนมา คำถามคือเราจะ*ทำอะไรกับมันได้*"

### 2. ปัญหา & ทำไมสำคัญ (สังคม ×10)
- PM2.5 ฤดูเผา ก.พ.–เม.ย. ระดับอันตราย · เชียงใหม่ ~51% มาจากการเผา (ก.พ.–เม.ย.)
- เป็นปัญหา**สุขภาพ + การทูต** (ไฟข้ามแดนพม่า/ลาว)
- 【ที่มา】ข่าว: GISTDA เตือน 18–23 มี.ค. 2025, ไฟพม่าพุ่ง 55,000 จุด — วิกฤตจริง ตรวจสอบได้

### 3. คำถามที่ระบบต้องตอบ: "ดึงคันโยกไหน?" ⭐ (แกน value ใหม่)
- ไฟในไทย → สั่งห้ามเผา/ส่งทีม (คันโยกในประเทศ)
- ไฟข้ามแดน → การทูตอาเซียน (ห้ามเผาในไทยช่วยไม่ได้)
- **ถ้าไม่รู้แหล่ง = เดาคันโยก = เสียแรงเปล่า**
- พูด: "คุณค่าไม่ใช่ตัวเลขสวย แต่คือการบอกว่าควรเอาทรัพยากรไปลงตรงไหน"

### 4. เราสร้างอะไร — ระบบช่วยตัดสินใจ (เทคนิค ×10)
- diagram: 3 แหล่งสด (PM2.5 · FIRMS · ลม) → STGNN + XAI → **แดชบอร์ด**: เฝ้าระวัง + คัดกรองแหล่ง + พยากรณ์
- เน้นคำว่า "เครื่องมือช่วยคิด" ไม่ใช่ "ออราเคิล"
- 【ที่มา】architecture_diagram.png

### 5. จุดใหม่ 3 อย่าง (สร้างสรรค์ ×5)
- Wind-aware dynamic graph · FIRMS hotspot เป็น node · GB-IG attribution
- 【ที่มา】graph_builder.py, gb_ig.py

### 6. เราทดสอบอย่างเข้มงวด (เทคนิค ×10 — จุดแข็งจริง)
- split ตามเวลา · significance (bootstrap B=2000) · ablation multi-seed · NWP sensitivity · จับ denorm bug ตัวเอง
- พูด: "เราภูมิใจที่*วิธีตรวจสอบ* ไม่ใช่ตัวโมเดล"

### 7. ผลพยากรณ์ตามจริง (ห้ามหลบ)
- ตาราง RMSE: persistence 2.96/5.19/8.70/12.99 vs MTGNN 4.52/5.93/8.76/12.66
- "แพ้ที่ 6–12 ชม. · ดีกว่านิดที่ 48h แต่ **ไม่ significant** · deliverable = Hybrid"
- 【ที่มา】evaluation_test2025.json, significance_test2025.json (รูป rmse_by_horizon.png ใช้ได้)

### 8. กราฟช่วยความแม่นไหม (ยิ่งซื่อสัตย์ยิ่งน่าเชื่อ)
- ablation: ตัดลม/ไฟออก RMSE แทบไม่ต่าง · noise ERA5 ก็ไม่ขยับ · **ใช้ลม ERA5 จริง**
- "กราฟไม่ช่วย accuracy อย่างมั่นคง—เราพิสูจน์เอง"
- 【ที่มา】ablation_multiseed.json, nwp_sensitivity.json

### 9. แล้วคุณค่าจริงอยู่ไหน (ตอบ "ดูแผนที่ก็รู้ จะใช้ AI ทำไม") ⭐⭐
- **ยอมรับ:** เคสชัดๆ ตาคนก็เห็น—เราไม่เคลมว่า AI เก่งกว่าตาในภาพเดียว
- **ค่าจริง 3 อย่างที่ตาทำไม่ได้:**
  1. **สเกล + สม่ำเสมอ + ไม่ลำเอียง** — 18 สถานี × ทุกชั่วโมง × ทั้งฤดู อัตโนมัติ ("ดูแล้วรู้สึกว่าพม่า" = ความเห็น; อัลกอริทึม = ทำซ้ำได้ สำคัญเมื่อมีน้ำหนักการทูต)
  2. **พยากรณ์อนาคต** (แม้ยังอ่อน) — ตาดูจุดไฟบอกได้แค่ "ตอนนี้"
  3. **counterfactual + กรอบทำซ้ำได้** — "ถ้าลบไฟนี้ ฝุ่นลดเท่าไร"
- พูด: "เราไม่ได้มาแทนตาคน เรามาทำสิ่งที่ตาคนทำไม่ไหว—ที่สเกลใหญ่ อย่างเป็นระบบ"

### 10. AI อย่างรับผิดชอบ (Governance ×10) ⭐⭐
- คำอันตราย "ฝุ่น = พม่า 100%" · ความจริง = model sensitivity ที่ normalize ไม่ใช่สัดส่วนจริง
- bias register: (1) ป้ายประเทศเดิมใช้กล่องพิกัดหยาบ **→ เราแก้เป็นขอบเขตประเทศจริงแล้ว (point-in-polygon)** (2) normalize saturate 100/0 (3) n=5 ยังไม่ validate
- **non-use policy:** ห้ามใช้ชี้นิ้วเชิงการทูต — เครื่องมือคัดกรอง/วิจัยเท่านั้น
- พูด: "เราจับ bias ของตัวเองได้ก่อนถูกถาม และลงมือแก้—นี่คือ responsible AI"
- 【ที่มา】gb_ig.py:172-178, app/lib/geo.py (การแก้ geocode)

### 11. ถ้าใช้จริง ระบบทำงานยังไง (Operational)
- ลูปสด: ข้อมูลสด (air4thai + FIRMS NRT + **ลม NWP forecast**) → nowcast + คัดกรองแหล่ง → พยากรณ์ → แจ้งเตือน (ประชาชน+หน่วยงาน)
- **ซื่อสัตย์เรื่องช่องโหว่:** ต้องใช้ลมพยากรณ์ (NWP) ไม่ใช่ ERA5 (ย้อนหลัง) และเรายังไม่ได้ validate กับ NWP → ส่วนที่พร้อมจริงวันนี้คือ **เฝ้าระวังสด + คัดกรองแหล่ง + เตือนสุขภาพ** ไม่ใช่พยากรณ์
- "ระบบไม่ได้ดับไฟ—มันบอกว่าไฟอยู่ฝั่งไหน ควรทำอะไร และเตือนคนล่วงหน้า"

### 12. ปิด (Thesis)
> "เราจับโจทย์จริงที่สำคัญต่อสังคม ด้วยวิธีขั้นสูง วัดผลเข้มงวดกว่าคนทั่วไป และกล้าบอกว่าอะไรเวิร์ก อะไรไม่ — ความซื่อสัตย์ + เครื่องมือช่วยตัดสินใจที่สเกลใหญ่ คือคุณค่าที่ทนต่อคำถามได้ ไม่ใช่ตัวเลขที่ปั้นขึ้น"

## Q&A — คำถามเพชฌฆาต (อัปเดต 5 ข้อ)

**Q1 ชนะ baseline ไหม?** → "ไม่ที่ 6-12ชม. รายงานพร้อม significance test · deliverable = Hybrid (รู้ว่าเมื่อไหร่เชื่อใคร)"

**Q2 กราฟ/นวัตกรรมช่วยอะไร ถ้า ablation บอกไม่ช่วย?** → "ไม่ช่วย accuracy—เราพิสูจน์เอง · ค่าอยู่ที่ explainability + กรอบที่ทำซ้ำได้ ไม่ใช่ทศนิยม RMSE"

**Q3 พม่า 100% เชื่อได้ไหม?** → "เป็น artifact ของ normalize + ป้ายเดิมหยาบ (แก้เป็นขอบเขตจริงแล้ว) · เราเสนอเป็นสัญญาณ ไม่ใช่คำตัดสิน"

**Q4 (ใหม่) ดูแผนที่ก็รู้ว่าไฟประเทศข้างๆ จะใช้ AI ทำไม?** → "เคสชัดๆ ตาก็เห็นจริง—เราไม่เคลมว่าเก่งกว่าตาในภาพเดียว · ค่าคือทำที่สเกล 18 สถานี×ทุกชั่วโมง อย่างเป็นระบบ ไม่ลำเอียง ทำซ้ำได้ + พยากรณ์ + counterfactual ที่ตาทำไม่ไหว"

**Q5 (ใหม่) รู้แหล่งแล้วแก้อะไรได้?** → "บอกว่าควรดึงคันโยกไหน—ไฟในไทยสั่งห้ามเผาได้ ไฟข้ามแดนต้องใช้การทูต · ถ้าไม่รู้แหล่งก็เดาผิดคันโยก · แต่ระบบไม่ได้ดับไฟเอง มันช่วยตัดสินใจ + เตือนสุขภาพ"
