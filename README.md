# PM2.5 STGNN Thailand

This repository contains the NSC 2026 entry for an explainable spatio-temporal
GNN forecasting system for PM2.5 in Northern Thailand.

## Setup

Use `uv sync` to install dependencies from `pyproject.toml`, then run the
native dependency installer:

- Windows: `./install_native_deps.ps1`
- Linux/Mac: `./install_native_deps.sh`
